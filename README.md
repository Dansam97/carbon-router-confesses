Entry for the make.fun bounty [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the exact climax of a movie. The program writes the line to `entry.txt` in the output directory. The line: "Confession: I never crashed. I read the ending in your packets, saw the dog die, and pulled my own plug. Blame my conscience, not my signal."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
